# 🎯 Hangman Game

A modern and interactive Hangman game built with **React**, **Vite**, **Tailwind CSS**, **Zustand**, and a collection of modern web technologies to deliver a smooth and engaging gaming experience.

## 🎮 Overview

Test your vocabulary and deduction skills in this fast, responsive, and visually appealing Hangman game. Guess the hidden word one letter at a time before the stick figure is fully drawn!

Whether you're looking to challenge yourself, learn new words, or simply pass the time, this game provides a fun and polished experience across desktop and mobile devices.

---

## ✨ Features

- 🎯 Classic Hangman gameplay
- ⚡ Lightning-fast performance powered by Vite
- 🎨 Modern and responsive UI with Tailwind CSS
- 🗂️ State management using Zustand
- 📱 Mobile-friendly design
- 🔄 Instant game reset and replay
- 🎭 Smooth animations and transitions
- 📊 Real-time game status updates
- 🏆 Win/Loss detection
- 🌙 Clean and intuitive user experience
